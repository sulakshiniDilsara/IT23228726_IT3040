# IT3040 - ITPM Assignment 1 (Playwright Automation)

## 📌 Overview
This repository contains the **Playwright automated test suite** for Assignment 1 of IT3040 - IT Project Management.  
The project tests the **Swift Translator** application (Singlish → Sinhala) across:
- 24 positive functional scenarios
- 10 negative functional scenarios
- 1 UI-related scenario

All test cases are automated using Playwright and mapped to the Excel test case sheet provided (`IT23228726.xlsx`).  

---

## 📂 Repository Contents
- `tests/translator.spec.js` → Playwright test scripts covering all scenarios  
- `test-data.json` → Structured test data converted from Excel sheet  
- `playwright.config.js` → Playwright configuration file  
- `package.json` → Project dependencies and scripts  
- `README.md` → Setup and usage instructions  
- `IT23228726.xlsx` → Original test case sheet (completed)
